# README and Project Documentation

## Workflow

1. Inspect the repository, manifest, framework configuration, migrations, scripts, and existing documentation.
2. Verify commands against the actual project instead of inventing setup steps.
3. Document prerequisites, installation, configuration, database setup, running, testing, building, and deployment.
4. Explain required environment variables without exposing values or secrets.
5. Include MySQL import paths, migration commands, and seed procedures when applicable.
6. Document common failure cases and diagnostic commands.
7. Link detailed references instead of duplicating lengthy setup material.

## README Sections

- Project purpose and audience
- Features
- Technology stack
- Prerequisites
- Installation
- Environment configuration
- Database setup
- Development server
- Tests and validation
- Build or deployment
- Folder structure
- API or usage notes
- Troubleshooting
- License and contributors if known
